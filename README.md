# My Personal Website

This is a React website built with Vite and published through GitHub Pages.

## Live website

[https://nplat15.github.io/myprofile/](https://nplat15.github.io/myprofile/)

## Local development

```sh
npm install
npm run dev
```

Every push to the `main` branch builds and deploys the site with GitHub Actions. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** to enable publishing.
